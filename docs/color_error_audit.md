# 色差误差链路审计

本文记录 2026-09-03 对“整体重建 → 材料模板匹配 → 光场重建 → 有符号色差”
链路的审计结论。目标是先消除坐标错配，再提高背景场表达能力；不能用在线颜色
补偿去掩盖几何错误。

## 1. 当前数据证据

当前 `20260902_220732_970967` 光场序列共有 1122 帧，其中 911 帧保存为有效观测，
211 帧被标定准入拒绝。有效观测的材料可见率中位数为 0.975，说明跟踪器长期把
接近完整的轮廓解释为模板子段，而不是绝对的完整材料区间。

保存观测中的跨时间近似往返帧显示出明显路径依赖：

| 帧对 | 中心线形状 RMS（去平移） | UV RMS | 规范 RGB RMS |
|---|---:|---:|---:|
| 80 / 1110 | 0.040 mm | 1.538 px | [0.069, 0.066, 0.055] |
| 76 / 1105 | 0.039 mm | 2.130 px | [0.068, 0.065, 0.055] |
| 333 / 610 | 0.051 mm | 0.907 px | [0.053, 0.053, 0.041] |

这不能证明全部 RGB 差都来自材料错配，因为真实位置和灯光也可能变化；但它证明
“几何几乎恢复”并不意味着 UV/材料对应恢复。1--2 px 的系统映射差足以在高梯度
光照条带处产生很大的线性 RGB 残差。

现有 direct checkpoint 在按训练时同一套稠密规范采样复算时，单帧留出误差约为
`[0.030, 0.036, 0.031]`。因此光场仍有提升空间，但不能先把全部误差归因于网络容量。

## 2. 根因与当前边界

旧在线匹配用长度阈值、上一状态子段搜索和时间传播推断材料区间，容易在弯曲过程中
累积坐标偏移。曾尝试从上下包络直线拟合物理端边，但这条证据在大曲率自遮挡时不
成立：下部遮挡上部形成的轮廓同样可以是横贯整块材料的直线，单目二值 mask 无法
把它与真实直端边区分。相关端边拟合、可观测判断、单端/双端分支和诊断字段均已删除。

当前规则只有一条：每个结构有效的规则轮廓都按三维累计弧长归一到配置的 55 mm
模板全区间；当前角度和原点直接替换上一状态，不做隐藏段传播、子段搜索或时间混合。
上下 2% 仅在左右 $X=\pm W/2$ 侧平面求解时排除圆角，不承担端边识别。重建管线
和模板格式版本已升级，旧光场模型和旧法向 LUT 会被拒绝，防止新旧语义混用。

这一规则消除了历史路径依赖，但不解决不可辨识性：自遮挡帧得到的只是可见轮廓的
规范参数，并不是真实物理材料坐标。需要物理对应时，采集必须避免这种遮挡，或增加
纹理/标记、深度信息或专门的多类别观测。

## 3. 光场模型精简

已删除以下无效或目标错位的机制：

- 局部几何从 15 维减为 10 维。当前直纹面模型中 `normal/tangent/curvature` 的 X
  分量及横向偏移的 Y/Z 分量理论恒为零。旧模型把约 `1e-6` 的浮点噪声标准化为
  单位输入，容易学习重建噪声。
- checkpoint 不再用“绝对 RGB + 几何差分 + 空间差分”的混合分数排名。两个差分项
  仍可作为训练辅助和诊断，但最佳模型只由最终任务的绝对留出 RGB RMSE 决定。
- 删除 direct 路径中不参与任何筛选的 `sample_filter.saturation_threshold` 配置。
- 删除两个只为混合 checkpoint 分数服务的 validation weight 配置。

以下机制保留：

- `side_edge_exclusion_ratio`：只从左右侧平面求解中排除上下圆角，不识别端边；
- UV 边界二阶平滑与 Huber：只抑制逐行分割噪声，不惩罚常量和线性修正；
- 单向弯曲投影：对应当前传感器的物理可行集合；
- 静态高分辨率 B、几何条件 delta B 和低频会话修正：分别处理固定纹理、弯曲响应
  与跨会话低频漂移，职责不重叠；
- 有符号 `camera - background` 残差：避免丢失变暗通道中的法向信息。

## 4. 重新标定与验收

管线语义改变后，必须重新生成观测、光场模型和法向 LUT：

```bash
uv run calibrate-lightfield --config config.yaml
uv run calibrate-norm --config config.yaml
```

材料模板由配置中的物理宽度、全长、`s=0` 端点和网格直接生成，不再存在单独的模板
采集步骤。上述参数、相机或重建语义改变后，必须重新生成光场模型和法向 LUT。

新一轮必须至少检查：

- 完整恢复帧的 `material_visible_fraction` 应为 1，而不是长期停在 0.97 左右；
- 平 → 弯 → 平的配对帧应同时报告中心线、UV 和规范 RGB 差，不能只看 3D 外形；
- checkpoint 选择使用绝对 RGB RMSE，几何/空间差分 RMSE只用于判断欠拟合方式；
- 训练与验证必须报告 B-only 和 B+deltaB，确认几何条件场在每个 RGB 通道都有稳定收益；
- 法向 LUT 只使用与最终运行完全相同的背景模型、材料模板哈希和有符号残差语义。
